# Go Archiver

My homemade stripped-down implementation of `tar` for .tar.gz archives management.
Built for learning purposes, not for production use!

**No AI was used to write a single line of code (or anything) in this project.**

*I've used it to troubleshoot some issues when I was stuck, but all content in
this repo has been written by myself exclusively. It will probably contain lots
of human errors, especially since it's a project done for fun and to learn new
stuff.*
